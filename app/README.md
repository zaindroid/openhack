# Antibiotic Watch — which drug-bug pairs are rising where, and why

**Track 03 · public good.** An explain-why agent over antimicrobial-resistance surveillance. It finds the (country,
pathogen, antibiotic class) pairs whose resistance rose fastest, tests four competing drivers with numbers, rejects the
ones the data does not support, and drafts what a health ministry should watch or change first. A human approves.

## Idea card

| | |
|---|---|
| **Problem** | Resistance to antibiotics is attributed to more than a million deaths a year. Surveillance reports show *that* resistance rose, rarely *why*: prescribing, veterinary use, importation — or a change in who reports. Ministries act late or on the wrong lever. |
| **Why now** | WHO GLASS and ECDC now publish comparable national series; consumption (ESAC-Net) and veterinary sales (ESVAC) are open; nobody joins them and asks "why" per pair. |
| **What it does** | Scout → competing causes → Skeptic with the SQL attached → ranked ministry drafts → memory so the next country's run is shorter. |
| **Who acts** | National AMR focal points, stewardship committees, agriculture ministries (One Health). |
| **Demo question** | *Which drug-bug pairs are rising fastest in which countries, why, and what should a health ministry watch or change first?* |

## How the Skeptic decides (all deterministic, all with SQL)

| cause | supported when | rejected when |
|---|---|---|
| `human_prescribing` | consumption of the class (DDD/1000/day) rose ≥ 10 % at lag 0–2 years before the rise | change below threshold, or a surveillance artifact fired |
| `livestock_use` | pathogen is a food-chain pathogen (`pathogens.zoonotic`) **and** veterinary sales (mg/PCU) rose ≥ 10 % | not zoonotic, or sales flat, or artifact |
| `surveillance_artifact` | labs added / definitions changed in the window **and** isolates jumped > 50 % in a year | no change, or isolates stable |
| `importation` | imported share of isolates ≥ 30 % and rising | below threshold or falling |
| `unexplained` | all four above rejected | anything supported |

A surveillance artifact **rejects** the biological causes: a +11-point rise across a year in which the isolate count
doubled is a reporting change until proven otherwise. The model (Nemotron via Meterless) explains the verdicts in plain
language; it never changes them.

## Data

Seed data is **illustrative** (`app/data/seed/README.md`), generated by `make_illustrative_seed.py` so that each path
is exercised once: DE E. coli / 3rd-gen cephalosporins (prescribing), PL Salmonella / fluoroquinolones (livestock),
IT K. pneumoniae / carbapenems (surveillance artifact), FR K. pneumoniae / 3rd-gen cephalosporins (unexplained),
ES E. coli / carbapenems (importation).

Real sources (all free; see fetchers in `app/data/`): ECDC Surveillance Atlas EARS-Net CSV exports
(`fetch_ecdc_atlas.py`), WHO GLASS downloads (`fetch_glass.py`, documented stub: no stable API), ECDC ESAC-Net
consumption (`fetch_esac.py`), EMA ESVAC/ESUAvet veterinary sales (manual table). `surveillance_changes` is hand-curated
from country notes — that curation is the honest cost of this idea.

## Run

```bash
pip install -r requirements.txt
python -m whycore.evals app/evals.yaml      # 6 cases, offline
uvicorn whycore.app:app --port 8080         # UI
```
`DATA_BACKEND=zetaris ZETARIS_REST=… ZETARIS_PREFIX=aw_pg.` reads the same tables through Zetaris after `app/schema.sql`
is loaded into Postgres and registered. `MODEL_BASE_URL`/`MODEL_API_KEY` switch the explainer from the offline
templater to Nemotron through Meterless.

## 90-second demo script

1. Open the UI, press **Run agent**. Five rising pairs appear, ranked by rise × isolates.
2. Click IT · K. pneumoniae vs carbapenems: *surveillance_artifact* supported — 14 labs joined in 2022, isolates 600 → 1 300.
   All biological causes rejected for that reason. First action: *audit before acting*. Hover a verdict: the SQL.
3. Click DE · E. coli vs 3rd-gen cephalosporins: consumption +36 % two years ahead → *human_prescribing* supported,
   livestock rejected (not a food-chain pathogen), import rejected (10 %). Approve "Stewardship review".
4. Click PL · Salmonella vs fluoroquinolones: veterinary sales +41 %, zoonotic → *livestock_use*; prescribing flat.
5. FR pair: everything rejected → *unexplained* → "Field investigation". Press **Run agent** again: warm run, 0 tests,
   memory skipped all remembered rejections.

## Sponsor mapping

- **Zetaris** — one federated query joins resistance, consumption, veterinary sales and surveillance notes from four
  agencies; `v_rising_pairs` is the semantic view the agent reads.
- **Meterless** — routes every explainer call to Nemotron and keeps the run memory (rejections per pathogen/class).
- **NVIDIA Nemotron** — Super for the ministry-facing explanation, Nano for formatting; no verdict is model-made.
- **Cursor** — build environment.

## Limits

Surveillance data is annual and uneven between countries; thresholds here are screening heuristics, not epidemiology.
This ranks **questions for epidemiologists**; it does not diagnose causes or recommend clinical treatment. Importation
shares exist only where reference laboratories flag travel history. Seed figures are invented.
