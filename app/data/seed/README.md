# Seed data — ILLUSTRATIVE

Every CSV in this folder is generated by `app/data/make_illustrative_seed.py`. The numbers are invented so that each
verdict path in `app/domain.py` is exercised once (prescribing, livestock, surveillance artifact, importation,
unexplained). They are **not** WHO GLASS, ECDC or EMA figures and must not be quoted as such.

## Replace with real exports

| file | real source | column mapping |
|---|---|---|
| `resistance.csv` | ECDC Surveillance Atlas → EARS-Net → indicator "R %" and "Number of isolates tested", one export per pathogen/antimicrobial group (`app/data/fetch_ecdc_atlas.py`) | `RegionName`→country (ISO-2 via lookup), `Population` (pathogen) → pathogen, `Indicator` → antibiotic_class, `Time` → year, `NumValue` → resistant_pct / n_isolates |
| `resistance.csv` (non-EU) | WHO GLASS annual data download (`fetch_glass.py`) | GLASS `Country`, `Pathogen`, `Antibiotic`, `Year`, `% resistant`, `N tested`, `Specimen/Setting` |
| `consumption.csv` | ECDC ESAC-Net database export (`fetch_esac.py`) | `Country`, `Year`, `ATC group` → antibiotic_class (J01DD→cephalosporins_3g, J01MA→fluoroquinolones, J01DH→carbapenems), `DDD per 1000 inhabitants per day`, `Sector` (community/hospital → human) |
| `livestock_use.csv` | EMA ESVAC / ESUAvet annual report tables | `Country`, `Year`, class, `mg/PCU` |
| `surveillance_changes.csv` | hand-curated from EARS-Net / GLASS country notes ("new laboratories", "case definition") | free text → `change` enum |
| `travel_import.csv` | national reference laboratory reports (travel-associated isolates) | share of isolates flagged imported |
| `pathogens.csv` | hand-curated | zoonotic flag with a note; change it with care, it gates the livestock cause |
